# 动量板块×动量股策略（Momentum Sector × Momentum Stock）

> [!WARNING]
> **探索性回测，不能按"历史股票数据齐全"验收。** 两轮独立审计（内部 + 外部 ChatGPT）发现的问题已修复并重跑（第 7 节）；
> 但仍有 **57 个历史代码 / 1.37% 的"股票 × 月份"** 没有可用的免费数据（第 5 节，逐个列在 `results/gap_ledger.csv`）。
> 样本外区间在修复前已被看过一次，属于**回顾性时间留出**，不是从未接触的样本外。

## 1. 策略（冻结于提交 `fbc4c51`，见 `FROZEN_SPEC.md`，早于本报告的所有数字）

每个月最后一个交易日收盘：
1. 每只当时的标普 500 成员计算 **12-1 动量** = P(t−1)/P(t−12) − 1。
2. 每个 GICS 行业（按当时的历史分类）的得分 = 合格成员动量的**等权平均**。
3. 买得分第一的行业里动量第一的**一只股票**，满仓持有一个月。
4. 平手按代码字母排序；成本每边 10bp（按交易前漂移权重）；退市按真实对价或最后成交价处理。

样本：持有月 2009-01 至 2026-09（213 个月）。样本内 IS = 前 149 个月（至 2021-05），样本外 OOS = 后 64 个月。参数网格只用到 2021-04 的数据挑选。

## 3. 解读

1. **样本内：年化收益和 SPY 一样（15.4%），但风险大得多。** Sharpe 0.62 对 1.02，最大回撤 −37% 对 −19%。2009–2020 年的 12 年里有 6 年跑输 SPY。
2. **样本外收益高，但非常集中。** 最好的 5 个月贡献了全期对数收益的 41%；全期去掉这 5 个月（改为 0%）后年化 16.8%。2026 年（至 9 月）+343%，主要来自新 SanDisk。主要赢家：NVDA、DVN、SNDK、NFLX、WDC。
3. **"先选行业"这一步仍然看不出增量价值。** 同样只买一只股票，不选行业的版本样本内 18.2%、样本外 91.4%，都高于主策略。配对 bootstrap 中，主策略不如不选行业的重抽样比例：样本内 71%（算术平均差）/ 59%（CAGR 差），样本外 69% / 65%。
4. **参数优化仍然不稳定。** 96 个配置的样本内与样本外 Sharpe 排名相关系数 −0.24。主策略在样本内排第 59/96。样本内最优配置在样本外 33.2%，好于 SPY，但低于主策略。
5. **统计显著性有限。** 主策略样本外 alpha t 值（Newey–West）1.92；Sharpe 的 bootstrap 5%–95% 区间：样本内 0.18–1.09，样本外 0.39–1.77。这些比例是基于已实现序列的重抽样份额，**不是 p 值，也不是未来跑输的概率**。

**结论**：修复后，主策略长期大致跟上或超过 SPY，但风险高得多，收益依赖少数极端月份。**没有证据表明"先选行业"能提高选股效果。** 证据既不支持"稳定 alpha"，也不足以彻底否定这个方法。

## 7. 审计与修复（`audit/`、`WORKFLOW_AUDIT.md`）

| 审计发现 | 修复 |
|---|---|
| 收购方接手代码，价格是别的公司（EP、CPWR、DD、CB、JCI、CCE、PARA） | `data/identity_resolutions.csv`（每条附证据）：CPWR、DD、CB 改用 WIKI 原公司价格；EP、JCI（Tyco 入指前）、PARA 2022–2025 排除；CCE、DD 2019 设价格断点。新增 `identity_check.py`（市值合理性 + 与 WIKI 交叉比对） |
| 行业用了现在占用代码的公司（Sprint→SentinelOne 等）、SEC 行业代码分错、2018/2023 年调整 | `build_sector_table()`：Yahoo 行业只在价格确认是同一家公司时使用；`data/sector_overrides.csv` 收录 59 条人工核对（含日期和来源，例如 EA、Twitter 2018-09-24 改行业，AppLovin 2026-07-31 改行业） |
| ETF 版本平手时结果随机 | 2018 年前电信和科技合并为一个 XLK 行业；所有排名按"值降序、代码升序" |
| 月中退市被当成正常月底卖出 | 月底价格必须是月底前 5 个交易日内的成交；退市按 `data/exit_resolutions.csv` 的真实对价（HSP、TECO、Andeavor、SCANA）或最后成交价，之后持有现金 |
| WIKI 停更规则用了"下个月的数据" | 已取消 |
| 截断测试和正式回测的数据准备不一致 | 共用同一个函数；截断测试加入 2026-01 和"不选行业" |
| 基本面 asof 返回尚未公布的字段；TTM EPS 混用拆股口径 | 每个字段单独控制；每季 EPS 先调到同一口径再相加 |
| 冻结记录被覆盖 | `FROZEN_SPEC.md` 先提交；每次运行存档 manifest |
| bootstrap 标签不精确；回撤没从初始净值算 | 分别报告算术平均差和 CAGR 差，并注明不是 p 值；回撤从 1.0 起算 |

修复前后的变化（主策略）：样本内 4.8% → 15.4%，样本外 87.4% → 71.3%，全期 24.8% → 30.0%。变化主要来自行业修正（EA、ATVI、IPG 等在 2018 年改行业）和身份修正。
