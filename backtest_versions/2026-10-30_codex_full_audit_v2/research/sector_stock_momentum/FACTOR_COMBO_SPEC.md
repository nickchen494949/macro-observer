# 因子组合体检规则（FACTOR_COMBO_SPEC）— 在看任何组合结果之前写定并提交

日期：2026-10-29 10:30（北京时间）。代码：`factor_combo.py`。结果：`results/factor_combo/`。
为什么要做：单因子体检（`FACTOR_SCREEN_SPEC.md`）的结论表是逐个因子判定的；组合起来可能有用：几个弱因子叠加，或者某个因子只在一部分股票里起作用（交互）。
面板、目标、股票池、47 个因子都与单因子体检相同（`results/factor_screen/panel_screen.parquet`；目标为下个月收益）。2019-12 以后的结果只作回顾性参考，不参与判定。

## A. 事先指定的经典组合（8 个；方向来自学术文献，不看数据定）
得分 = 各因子当月横截面百分位排名的等权平均（"−"表示取反），至少一半的因子有数据才打分。评估区间：形成月 2010-01 … 2019-11（组合不需要拟合，所以全段都可用于评估）。
| # | 名称 | 因子 |
|---|---|---|
| A1 | 价值 + 动量 | bm, ep, sp, mom_12_1 |
| A2 | 质量 + 价值 | roe, gp_a, −accruals, −leverage, bm, ep |
| A3 | 动量 + 低波动 | mom_12_1, −vol_3m |
| A4 | 动量 + 盈利惊喜 | mom_12_1, sue, ear |
| A5 | 合理价格的成长（GARP） | rev_g, eps_g_sym, roe, ep |
| A6 | 动量 + 营收/毛利加速 | mom_6_1, rev_accel, gm_chg |
| A7 | 质量 + 动量 + 价值 | roe, gp_a, −accruals, mom_12_1, bm, ep |
| A8 | 动量 + 短期反转 | mom_12_1, −rev_1m |
多重检验：对 8 个组合的月度 IC 做 Romano–Wolf 校正（平稳块自助法，平均块长 6 个月，2,000 次）。

## B. 机器学习组合（47 个因子全部放进去）
模型：Ridge（alpha = 10）、LASSO（alpha 用训练期内按年份的时间序列交叉验证选择）、LightGBM（与单因子体检相同的固定参数）。输入为当月横截面排名（Ridge / LASSO 缺失填 0 = 中位数；LightGBM 保留缺失）；目标为下月收益的横截面排名。
滚动：用 2010 至 Y−1 训练，在 Y 年测试，Y = 2013 … 2019（全部是没参与训练的样本外月份）。之后同样的流程继续滚到 2020 … 2026，作为回顾性参考。
多重检验：对 3 个模型 2013–2019 的样本外月度 IC 做 Romano–Wolf 校正。

## C. 数据驱动的交互搜索（"B 因子只在 A 高的股票里有用"）
- **搜索期**：形成月 2010-01 … 2015-12。对所有有序因子对（A, B），共 47 × 46 = 2,162 对：每月取 A 排名前 30% 的股票，算 B 与下月收益的 IC，再求月均和 NW t 值。按 |t| 选出前 10 对，方向取搜索期的符号。
- **检验期**：形成月 2016-01 … 2019-11（搜索时没碰过）。只检验这 10 对，用 Holm 校正。

## 组合收益
每个得分每月取前 10%（约 50 只）等权持有一个月，成本为每边 10 个基点 × 实际换手。比较对象：同一股票池等权（每月再平衡）和 SPY。

## 判定（事先定好，不再修改）
- **有用**：所在家族校正后 p < 0.05（A、B 用 Romano–Wolf，C 用 Holm），**且** 评估期内至少 70% 的年份 IC 与整体同号，**且** 前 10% 组合扣成本后的年化收益高于等权股票池。
- **没用**：未校正 |t| < 1.5，或者前 10% 组合扣成本后跑输等权股票池。
- **不确定**：其余情况。
- 评估期：A 为 2010-01 … 2019-11；B 为 2013 … 2019 的样本外；C 为 2016-01 … 2019-11。

## 输出
`results/factor_combo/combo_table.csv`（每个组合一行：家族、IC、t 值、校正后 p、年份同号比例、前 10% 组合年化与超额、判定、2020–2026 回顾性 IC 与超额），`yearly_ic.csv`，`pair_search_top.csv`，各组合的月度收益文件；日志 `logs/factor_combo.log`。
