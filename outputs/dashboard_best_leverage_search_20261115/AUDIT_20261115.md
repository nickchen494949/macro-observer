# 审计：`dashboard_best_leverage_strategy_search.py` / S6b “黄金红绿灯”（2026-11-15）

复现：`python3 outputs/dashboard_best_leverage_search_20261115/audit_s6b.py`（日志 `audit_s6b_log.txt`）

## 结论
S6b 不能升级为默认规则。自动仓位继续用 `B5 = TQQQ + SEP + 波动率管理`。之前说的 “41 年通杀”“样本外双向跑赢”“2010–2026 零误伤” 都不成立，看板文字已更正。

## 严重
1. **规则是看完结果后修补出来的，2010–2026 不是样本外。** S2e/S4/S6b 是第一轮结果出来后才加的，之后又做了两次修补，专门去掉 2010–2011 年的误报：(a) FINRA 见顶要求 2 年累计增速 > 0，去掉 2010-06..2011-04；(b) Sahm 必须是“仍在恶化”的衰退，去掉 2010-07。2010–2026 年化跟着这些修补一路上升：S2e `33.2% → 36.2% → 37.2%`，S6b `37.2% → 40.2% → 41.0%`。
2. **2010–2026 的超额几乎全来自 2020 年 3–4 月。** S6b 与 B5 只有 25 个月持仓不同，其中收益最高的 3 个月贡献了全部超额的 101%（2020-03 一个月就是 +36 个点）。逐月差 t = 1.37，块自助法 P(超额 ≤ 0) = 0.10，不显著。
3. **“恐慌抄底”主要等于提高平均仓位。** 平均 TQQQ 仓位从 69% 升到 74%。把恐慌规则反过来（不恐慌时才加仓），2001–2026 年化仍有 24.2%，和 S6b 的 24.6% 几乎一样，只是回撤更大。另一个对照：把波动率缩仓改温和（`sqrt(w)`），2001–2026 年化 25.4%、2010–2026 年化 41.7%，不用任何面板指标就打平甚至更高（但日频回撤 -54%）。恐慌信号的唯一价值是在相近年化下回撤比“统一抬高仓位底线”略小，这点证据很弱。
4. **走前测试其实输给了 B5。** 每年只用过去数据挑策略，2001–2026 年化只有 15.7%（按 Sharpe 挑）/ 16.8%（按 Calmar 挑），低于固定 B5 的 17.1%。而且候选池里已经包含了用后视镜设计的 S6b，就这样还是输。上一轮报告里“自 2019 年起被算法锁定第 1”的说法有误导性。

## 中等
5. **“41 年”证据其实只覆盖 2001–2026。** FMS 数据 2001 年才开始，FINRA 1998 年，CFTC 2006 年。1985–1997 年间 S6b 和 B5 只有 4 个月持仓不同。41 年最大回撤 -61.1%（1989-09 → 1990-10）S6b 完全没有改善。
6. **破位护栏只在 2 个事件上验证过（2000、2008），而规则正是照着这两次设计的。** 在 2001–2026 它确实把这两段回撤从 -33%/-37% 压到了 -15.5%/-17.8%，但样本只有 2 个，属于循环论证。
7. **阈值没有预先登记。** FMS ≥ 5.3%、融资同比 ≤ -15%、CFTC ≤ -1.2σ、仓位底线 0.80 都是作者自己选的。敏感性测试：底线 0.6 / 0.8 / 1.0 对应 2010–2026 年化 39.1% / 41.0% / 42.6%。单独用 FINRA 只有 38.1%，结论随参数变化。
8. **FMS 数据有缺口。** 2018 年以前每年只有约 4 个点，靠“75 天内有效”的规则沿用旧值（2001 年以来 310 个月里 269 个月可用）。缺口已在这里列明，尚未补齐月度数据。
9. **看板和规则对不上。** 卡片名和指标写的是 S6b，实际仓位计算仍是 B5（`server.js` 第 2164 行）。已改回 B5 的名称和数字。

## 已检查，无问题
- 执行时点：改成“收盘出信号、次日收盘成交”后，B5 年化 38.1%、S6b 43.8%，排序不变，不是同日收盘成交造成的偏差。
- 数据发布滞后：FINRA 用滞后 1 个月的数据，CFTC 滞后 3 天，FMS 以发布日为准，Sahm 用上月实时值。没发现前视偏差。
- 组合 E 中 “70% V4.1 + 30% S6b” 的 Sharpe 1.47 对比纯 V4.1 的 1.46，差距在噪声范围内；而且 V4.1 本身也基于样本内参数。

## 怎样才能证明 S6b
在不改任何参数的前提下继续向前跟踪，并在看板上并排显示 S6b 与 B5，攒到下一次真实的衰退或泡沫事件再评判。在那之前，FINRA 见顶回落、Sahm、FMS 恐慌这几项只作人工参考。
