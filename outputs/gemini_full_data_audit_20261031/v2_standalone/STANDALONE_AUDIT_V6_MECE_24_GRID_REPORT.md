## 1. Unified MECE Framework & Clean-Room Execution Standard

Every single cell in this report is evaluated under **one identical Clean-Room execution standard**:
- **Execution**: **Next-Day Open-to-Open (`Open[t+1_day1] -> Open[t+2_day1]`)**, signal observed at month-end `t` close.
- **Portfolio Weighting**: **Drifted Weights** (`w_drift` from actual stock returns during month `t -> t+1`).
- **Transaction Cost**: **`0.1%` (`10bp`) per side** (both `Additive` and `Self-Financing` reported side-by-side; difference is `<= 0.03%/yr` across all 24 cells).
- **Clean-Room Data**: 100% reconstructed from raw JSON prices/opens + raw SEC FSDS `sub_*.parquet` + raw PIT S&P 500 membership (`0` project imports, `0` intermediate panel reads, `0` `ticker_aliases_used.csv` reads).
- **3 × 2 × 4 = 24 MECE Combinations**:
  - **3 Ranking Momentum Horizons**: `12-1` (`Close[t-1]/Close[t-12]-1`), `6-1` (`Close[t-1]/Close[t-6]-1`), `3-1` (`Close[t-1]/Close[t-3]-1`)
  - **2 Concentrations (`Top-K`)**: `Top-1` (`k=1`), `Top-3` (`k=3`, equal `1/3` slot targets)
  - **4 Risk Controls**:
    1. `无风控 (None)`
    2. `RS(6-0) > Benchmark` (slot goes to 3M T-Bill `CASH` if `RS(6-0) <= Benchmark RS(6-0)`)
    3. `SMA200` (Primary table uses `Pass-Down 顺延下一名`; Supplementary table 1B reports `Gate-to-Cash 破位转现金`)
